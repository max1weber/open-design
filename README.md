# Mijn Thuisbatterij Design System

The official design system for [Mijn Thuisbatterij](https://www.mijnthuisbatterij.nl/) — a Dutch home-battery advisory tool by Studio Nieuwe Weide.

## Files

- [`design-systems/mijn-thuisbatterij/DESIGN.md`](design-systems/mijn-thuisbatterij/DESIGN.md) — Design system prose: visual theme, color palette, typography, components, layout principles, and agent prompt guide.
- [`design-systems/mijn-thuisbatterij/tokens.css`](design-systems/mijn-thuisbatterij/tokens.css) — CSS custom properties (design tokens).
- [`design-systems/mijn-thuisbatterij/components.html`](design-systems/mijn-thuisbatterij/components.html) — Standalone component fixture / reference HTML.

## Brand Summary

- **Palette**: Dark Green `#0E3D23` · Emerald Green `#00A36F` · Yellow `#FFCD00` · Orange `#E94E1B` · Light Blue `#9CD6E8`
- **Display typeface**: Tilt Warp (Google Fonts) — headers, subheadings, CTA labels
- **Body typeface**: Outfit Light 300 (Google Fonts) — body copy
- **Mascot**: Dongel — a smiling light-blue plug character used as the feature-list bullet icon
